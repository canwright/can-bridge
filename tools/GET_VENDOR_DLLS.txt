================================================================
  厂商 DLL 从哪来 —— 本仓库【不包含】任何厂商二进制
================================================================

  为什么不打包：
    这些 DLL 是各厂家的版权作品，EULA 明确禁止再分发。
    把它们放进公开仓库是侵权，也会让整个项目无法合法发布。

  所以：请按下面的方式【自己获取】。
        装完对应厂家的驱动后，DLL 通常就在系统目录里，桥能直接找到。


────────────────────────────────────────────────
  一、按你用的盒子，挑需要的
────────────────────────────────────────────────

  ┌ 周立功 USBCAN-E-U / 2E-U / 4E-U / 8E-U
  │   需要：USBCAN_E.dll（在 SysWOW64）
  │   来源：周立功官网 → 下载中心 → USBCAN-E-U 驱动
  │         https://www.zlg.cn/
  │
  ├ 周立功 经典 USBCAN-I / II
  │   需要：ControlCAN.dll / USBCAN.dll
  │   来源：同上，ZLG USBCAN 全系列驱动包
  │
  ├ 创芯 CANalyst-II
  │   需要：ControlCAN.dll（创芯版，约 2 MB）
  │   来源：创芯官网 / 随设备光盘
  │         （注意：和 ZLG 的 ControlCAN.dll 同名但不同厂，别搞混）
  │
  ├ PEAK PCAN-USB
  │   需要：PCANBasic.dll
  │   来源：https://www.peak-system.com/ → Downloads → PCAN-Basic
  │         装完 PEAK 驱动后自动在 SysWOW64，无需额外复制
  │
  ├ 广成 GCAN
  │   需要：ECanVci.dll + CHUSBDLL.dll
  │   来源：https://www.gcan.com.cn/ → 二次开发资源下载
  │
  ├ Vector VN 系列
  │   需要：vxlapi.dll
  │   来源：https://www.vector.com/ → XL Driver Library
  │         （要注册账号；本项目默认关闭 Vector 后端）
  │
  └ 同星 TOSUN
      需要：TSMaster.dll / libTSCAN.dll
      来源：同星官网


────────────────────────────────────────────────
  二、放哪
────────────────────────────────────────────────

  桥加载后端 DLL 的顺序（见 src/UniVciBridge.c 的 LoadVciNear）：

      ① <上位机程序目录>\kerneldlls\      ← 有些软件把插件放这
      ② <上位机程序目录>\                 ← 大多数情况放这
      ③ 系统搜索路径（SysWOW64 等）        ← 装过驱动就在这里，通常不用复制

  ★ 最简单：把对应厂家的驱动装上，让 DLL 落在 SysWOW64，
    桥自己就能找到，一个文件都不用复制。

  ★ 只有在"上位机目录里需要一份"的情况下（比如某些软件按名字加载），
    才把它复制到上位机程序目录。


────────────────────────────────────────────────
  三、验证桥有没有找到
────────────────────────────────────────────────

  跑一次上位机，然后看日志（程序目录\UniVciBridge.log）：

      后端: VCI 兼容 USBCAN_E.dll（型号 21 能打开）   ← 找到了
      VCI: USBCAN_E.dll 导出齐全，但打不开任何设备    ← 找到了 DLL，但硬件没插/被占用
      PCAN: PCANBasic.dll 存在，但打不开任何通道       ← 同上

  三行里最后一行决定一切。


────────────────────────────────────────────────
  四、绝对不要做的事
────────────────────────────────────────────────

  ✗ 不要把厂商 DLL 提交到这个仓库（会被拒，且是侵权）
  ✗ 不要替换 C:\Windows\System32 或 SysWOW64 里的原厂 DLL
     （要替换也只在【上位机程序目录】里换，或用 App.exe.local）
  ✗ 不要在没有备份的情况下删除厂家文件

  恢复：用「一键恢复.exe」，或参考 docs/01-验证记录与排查手册.txt
